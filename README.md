# DigiVerse — Design Your Digital Future

> **“The future isn't a destination. It's something we design.”**

**DigiVerse** is a competition-level, interactive digital exhibition and web platform exploring how human intentionality and intelligent systems shape tomorrow across:
* Artificial Intelligence (Symbiotic Cognition)
* Smart Cities (Biophilic Urban Metabolisms)
* Future Healthcare (Predictive Cellular Guardianship)
* Future Education (Adaptive Socratic Inquiry)
* Sustainable Technology (Regenerative Silicon & Circular Compute)
* Human Connection (Mindful Presence & Neuro-Sovereignty)

---

## 🏛️ Design Philosophy

Departing decisively from saturated neon cyberpunk cliches, DigiVerse follows the ethos of **Apple design + modern architecture + calm futuristic technology**:
* **Color Palette**: Warm ivory (`#FAF8F5`), soft off-white (`#F5F2EC`), light stone, muted sage green, dusty blue, soft lavender, and deep charcoal typography.
* **Interaction**: Editorial typography, micro-interactions, responsive physics-driven canvas filaments, smooth scroll transitions, and zero visual clutter.

---

## ⚡ Core Features

1. **Editorial Hero & Organic Flow Canvas**:
   - Interactive particle filaments and node connectivity responding smoothly to cursor velocity.
   - Editorial headline and live speculative metrics.

2. **The Agency of Choice (Manifesto)**:
   - Interactive comparison between passive technological drift and intentional human-centered design.

3. **Six Directions. One Unified Future**:
   - 6 interactive domain cards with bespoke line iconography.
   - Deep inspection modal drawers detailing foundational technologies, societal impacts, ethical dimensions, and pilot initiatives.

4. **Future Timeline (2026—2050)**:
   - Speculative progression across four major horizons: *The Ambient Foundation*, *Adaptive Ecosystems*, *Symbiotic Synthesis*, and *Harmonic Interconnection*.
   - Probability estimators and human experience vignettes.

5. **The Future Simulator (Main Interactive Feature)**:
   - 6-step systemic decision engine:
     - Step 1: AI Integration (Low ↔ High)
     - Step 2: Sustainability (Traditional ↔ Regenerative)
     - Step 3: Smart Cities (Conventional ↔ Fully Connected)
     - Step 4: Human-AI Collaboration (Independent ↔ Collaborative)
     - Step 5: Education Model (Traditional, Hybrid, Immersive, AI-Personalized)
     - Step 6: Healthcare Model (Reactive, Preventive, Personalized, AI-Assisted)
   - Real-time reactive calculation of 5 Systemic Equilibrium Scores:
     - Innovation Score
     - Sustainability Score
     - Human Impact Score
     - AI Integration Score
     - Digital Wellbeing Score
   - Archetype Matching (*The Regenerative Architect*, *The Human-Centric Guardian*, *The Symbiotic Pioneer*, etc.).
   - Actions: Save to DigiVerse public repository, copy summary, download JSON specification, or recalibrate.

6. **A Day in the Future (City 24h Cycle)**:
   - 24-hour interactive cycle (Morning, Afternoon, Evening, Night) with ambient environmental transitions and interactive hotspots.

7. **Human + Technology Axioms**:
   - Three non-negotiable principles: Human-Centered, Responsible, and Regenerative.

8. **The Future Has Questions (Ethical Challenges)**:
   - 8 expandable critical dilemmas addressing neuro-privacy, algorithmic bias, technological feudalism, and ecological limits with concrete countermeasures.

9. **Ask the Future (Speculative AI Assistant)**:
   - Minimalist conversational assistant with suggested prompts and reasoned speculative insights.

## 🚀 Quick Start

### 1. Backend Server
```bash
cd server
npm start
# Server runs on http://localhost:5005
```

### 2. Frontend Client
```bash
cd client
npm run dev
# Client runs on http://localhost:3333 (proxies /api to http://localhost:5005)
```

### 3. Production Build
```bash
cd client
npm run build
```

---

## 🛠️ Tech Stack
* **Frontend**: React 18, Tailwind CSS, Framer Motion, Lucide React, HTML5 Canvas API, Web Audio API.
* **Backend**: Node.js, Express.js, CORS, Dotenv.
* **Storage**: Dual-layer architecture: MongoDB via Mongoose when configured, with automatic fallback to local JSON file persistence for 100% zero-configuration reliability.
